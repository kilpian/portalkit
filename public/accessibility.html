Accessibility Statement

Last updated: May 2026

Kilpian LLC ("PortalKit") is committed to ensuring digital accessibility for people with disabilities. We continually improve the user experience for everyone and apply relevant accessibility standards.

Conformance Status

We aim to conform to the Web Content Accessibility Guidelines (WCAG) 2.1 Level AA. These guidelines explain how to make web content more accessible to people with disabilities. Conformance with these guidelines helps make the web more user-friendly for everyone.

Measures We Take

  • Skip navigation links to allow keyboard users to bypass repeated content
  • Semantic HTML landmarks (main, nav, footer) for screen reader navigation
  • Sufficient color contrast ratios (4.5:1 minimum for text)
  • Visible focus indicators for all interactive elements
  • Descriptive aria-labels on icon-only buttons
  • Keyboard-accessible navigation throughout the application
  • Form fields with associated labels
  • Alt text on meaningful images

Known Limitations

While we strive for full WCAG 2.1 AA compliance, some areas are still being improved. We are actively working to address any gaps and welcome feedback to help us prioritize fixes.

Technical Specifications

PortalKit relies on the following technologies for conformance with WCAG 2.1:

  • HTML5
  • CSS3
  • WAI-ARIA
  • JavaScript (React)
